سوق التل (Ell Tall Market) - دليل التشغيل السريع
=================================================

👋 مرحباً بك في تطبيق سوق التل!

هذا التطبيق هو المنصة المتكاملة لإدارة وعرض المنتجات وتسهيل عمليات البيع والشراء مباشرة.

متطلبات التشغيل:
- نظام تشغيل Windows 10 أو Windows 11 (64 بت فقط).

- اتصال نشط بالإنترنت لتسجيل الدخول ومزامنة البيانات.

للمزيد من الدعم والاستفسارات، يرجى زيارة موقعنا الإلكتروني.

Ell Tall Market - Quick Start Guide
===================================

👋 Welcome to Ell Tall Market!

This application is a complete platform designed to manage and browse products, facilitating buying and selling operations seamlessly.

System Requirements:
- Windows 10 or Windows 11 (64-bit only).
- Microsoft Visual C++ 2015-2022 Redistributable (x64) (automatically installed if missing).
- Active internet connection for login and synchronization.

For support and feedback, please visit our official website.
